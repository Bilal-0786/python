# Python

This repository was created **only for learning and practicing Git & GitHub**.

It is not intended to be a production-ready or useful Python project. It currently contains **two beginner-level CLI applications** built with Python.

## Purpose

The main purpose of this repository is to practice:

- Git basics
- GitHub workflow
- Version control
- Commits and branches
- Adding, modifying, and removing files
- Managing a GitHub repository

## Projects

The repository currently contains two **CLI (Command-Line Interface) applications** developed for Python beginners.

> These projects are primarily for learning and practice rather than real-world use.
